# Platform icons

Upwork, Freelancer, YouTube, Twitch, Patreon and Bilibili are from Simple Icons 15.22.0
(https://simpleicons.org, CC0 1.0), with each brand's colour set as the fill. The marks are the
platforms' trademarks and are used only to label each platform's rows. Contra is not in Simple Icons and
Fiverr's Simple Icons mark is its wordmark (unreadable at 16 px), so contra.svg and fiverr.svg are plain
letter marks drawn for Side Pocket.
